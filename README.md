# ReadLater —— 自建稍后读 / 收藏整理系统

微信场景的「文章 / 视频 / 图片」收集 + 稍后读 + 回顾，全部数据在自己手里。
后端 Python FastAPI + SQLite，跑在本地 Mac；前端零构建单页 Web，Mac / Linux / iPhone / Android 浏览器通用。

## 启动

```zsh
./run.sh
# 或
/Users/shiyusheng/.workbuddy/binaries/python/envs/default/bin/python -m uvicorn server:app --host 0.0.0.0 --port 8765
```

- 本机访问：<http://localhost:8765>
- 局域网访问（iPhone 同 Wi-Fi）：`http://<Mac 的 IP>:8765`，Safari「添加到主屏幕」即成 App 图标
- 首次运行依赖：`pip install fastapi uvicorn httpx beautifulsoup4 python-multipart`（装进隔离 venv，勿全局装）

## 收件方式（按优先级）

1. **界面粘贴框**：首页顶部粘贴任意链接，回车即收。文章 / 视频链接 / 图片 URL 自动识别类型。
2. **GET /collect 通道**（Bookmarklet / 快捷指令全走它）：
   ```
   http://localhost:8765/collect?url=<URL编码后的链接>&note=备注
   ```
   Bookmarklet（浏览器书签，在目标页面点击即收）：
   ```javascript
   javascript:location.href='http://localhost:8765/collect?url='+encodeURIComponent(location.href)
   ```
3. **图片上传**：首页「传图片」按钮，直接入库。
4. （规划中）iOS 分享扩展、订阅号收件通道。

## 功能

- **清单**：未读 / 已读 / 全部 × 文章 / 视频 / 图片 / 网页 类型筛选，标签筛选，全文关键词搜索
- **阅读**：打开即自动标记已读；正文为**全文缓存**——公众号文章删了也能读（图片已转存本地）
- **标签 / 笔记**：每条可打多标签、写想法；已读后的批注可回流 flomo（Pro API，规划中）
- **时间线**：月历选日期（有记录的日期带标记点、今天高亮、悬停显示「收藏/已读/回顾」分项计数）→ 下方时间轴展示当日记录流（左侧时间标签 + 虚线轨道 + 事件卡，区分收藏/已读/回顾三类事件，点卡片直接进阅读器）；支持月份前后翻页
- **统计**：四格总览（累计收藏/已读/连续回顾/标签数）+ **近半年活动热力图**（收藏 / 回顾双模式切换，GitHub 式周对齐网格，悬停看单日次数）
- **侧栏外壳**：左侧固定玻璃侧栏（桌面常驻 / 移动端滑入抽屉）——导航（未读 / ★收藏 / 回顾 / 时间线 / 统计）+ 标签区；标签项 = 彩色标识 + 名称 + 计数 + `⋯` 菜单（改名 / 置顶 / 改色 / 删除），点标签即过滤清单
- **标签管理**：`tags` 表只存元数据（颜色 / 置顶），条目标签成员仍用 items.tags 逗号存储（零迁移）；打标签时自动登记并分配默认色（同名恒同色，crc32 哈希）；改名会同步改写所有条目，删除会从所有条目剥离并返回影响条目数
- **界面**：Apple 官网风格——中性冷灰底（#f5f5f7）+ 纯白卡片（无边框无阴影，靠灰白对比与发丝线分区）+ 单一蓝 #0071e3 强调 + 全无衬线字体（大字号 / 负字距 / 600 字重建层级）；胶囊按钮（radius 980px）；半透明模糊仅用于导航栏与菜单；热力图为蓝色阶；已适配 `prefers-reduced-motion` / `prefers-reduced-transparency` 与旧浏览器实底降级
- **回顾**：Readwise 式每日卡片流——每天最多 5 张，三档反馈排期（快看 7 天 / 还行 14 天 / 已熟 28 天，间隔随曝光次数拉长、上限 180 天）；★ 收藏间隔缩短且优先重现；按类型轮转混排；进度条 + 连续天数；键盘 1/2/3/0/F；「历史上的今天」保留在队列下方
- **URL 去重**：同链接重复收集自动跳过
- **抓取失败兜底**：网络失败时仍入库存链接，不丢内容

## 网络分流（国内网络环境适配）

- 微信域（`mp.weixin.qq.com` / `mmbiz.qpic.cn`）：**直连**（国内可达，实测 200）
- 其他外网域：先直连，失败自动走代理兜底
- 代理优先级：环境变量 `READLATER_PROXY` > 系统代理环境变量 > `http://127.0.0.1:7897`（Clash 默认混合端口，与本机 Clash Verge 配置一致）

## 数据

- 数据库：`data/readlater.db`（SQLite，**WAL 模式**；`-wal` / `-shm` 文件是正常的，勿删）
- 图片：`data/images/`
- 备份 = 复制 `data/` 目录（WAL 下建议先停服务再拷贝，或连 `-wal` 一起拷）
